EXPERIMENT NO. 2
Aim

To write a Python program using branching statements (if-elif-else) to classify the batting, bowling, fielding and overall performance of cricket players.

Algorithm

Step 1: Start.
Step 2: Enter the runs scored, balls faced, wickets taken, runs conceded, overs bowled and catches taken for each player.
Step 3: Calculate Batting Strike Rate.

Strike Rate = (Runs Scored / Balls Faced) × 100

Step 4: Calculate Bowling Economy Rate.

Economy Rate = Runs Conceded / Overs Bowled

Step 5: Use if-elif-else to classify batting performance.
Step 6: Use if-elif-else to classify bowling performance.
Step 7: Use if-elif-else to classify fielding performance.
Step 8: Determine the overall All-Rounder performance.
Step 9: Display the result.
Step 10: Stop.

Output:
Player 1
Strike Rate: 296.0
Economy Rate: 14.5
Batting: Excellent Batter
Bowling: Average Bowler
Fielding: Outstanding Fielder
Overall: Needs Improvement

Player 2
Strike Rate: 288.71
Economy Rate: 10.67
Batting: Excellent Batter
Bowling: Average Bowler

Overall: Needs Improvement
